# 日文練習 PWA V1.5.14

日本語詞彙、五十音手寫與讀音練習，可安裝為離線 PWA。學習資料存在裝置上的 IndexedDB。Google Drive 負責備份及跨裝置學習紀錄，Cloudflare Worker 搭配 D1 處理每日提醒。

## V1.5.14 使用變更

- 首頁可直接進入「相似字形讀音」。手寫、五十音讀音及單詞讀音的「選擇假名行」預設收合，摘要顯示目前選擇。點選即可展開所有清音、濁音與半濁音。
- 相似字形完成頁每頁顯示 20 筆。勾選「只看錯題」會顯示原題號、你的答案與正確拼音，補練也會列入。
- 單字庫支援全形和半形搜尋，五十音順依假名讀音排序。切換排序保留查詢內容。新增與編輯可正常選詞性、JLPT 等級與頻率加權。舊版已存成錯誤文字的詞性與等級，可在編輯時重新指定。
- 讀音與手寫 CSV 新增尾欄「紀錄ID」。可匯入舊格式，也可重複匯入新版 CSV 或學習 ZIP。單詞讀音原本已有 ID。一般 Google Drive 完整備份及加密設定檔沿用原格式。
- 設定頁重新整理時保留欄位、展開的子區塊與捲動位置。版本資訊位於「設定 → 進階與資料管理」的「版本資訊」區塊。開啟時自動檢查，也可按「檢查更新」。練習結束、對話視窗關閉及資料儲存完成後才切換版本。
- 後端服務版本為 V1.4.2。相同提醒時間及時區的背景登記沿用待送或重試的排程，已準時完成練習的裝置會跳過當次提醒。

完整異動檔名與測試結果見 `CHANGELOG.md`。

## 沿用 V1.5.13 的相似字形練習

入口：練習 → 上方模式選單 →「相似字形讀音」。

- 合併 あお、こニ、せサ、さこ、ぬめ、ねれわ、るろ、ウワ、タク、シッンツ、ソン，共 11 組。
- 跨組重複字形去重後共 23 個字形，平假名與片假名混合隨機出題。可選每字 1／2／3／5／10 次；例如 3 次共 69 題，每個字形均會練到，且不連續出現相同字形。
- 使用羅馬拼音作答，沿用鍵盤常駐、Enter 送出並換題、答對／答錯／完成音效；錯題追加到最後再練。
- 完成總表列出每次作答（含補練）、題目、使用者答案及正確答案；答對藍色、答錯紅色。
- 「ッ」沒有獨立讀音，本模式用日文輸入碼 xtsu／ltsu 識別，這不是發音拼音；畫面以小字顯示並提供提示，隱藏單字發音按鈕。「ツ」才接受 tsu／tu。
- 最後使用的模式會保存。重複次數與五十音讀音共用，紀錄納入五十音讀音統計（含小促音，共 143 字形）、既有完整雲端備份與跨裝置紀錄合併；模式選擇納入加密設定匯出。
- 本功能離線可用、不呼叫 Gemini，不需額外 API 設定。

驗證：語法檢查及 208 項測試通過，包含原流程回歸、混合題庫、去重、隨機重複、ッ／ツ判定、錯題補練、同一輸入框、結果總表與備份合併。未完成 iPhone／iPad 真機及真實 Google 帳戶驗證。

本次新增檔案：similar-kana.js、test-similar-kana.mjs。
主要修改：app.js、kana-reading.js、settings-vault.js、style.css、sw.js；版本入口、manifest、package 與相關回歸測試同步更新。完整覆蓋此包內檔案，保留原網站位置與使用者瀏覽器資料。


## 沿用 V1.5.12：濁音與半濁音

- 五十音手寫、五十音讀音、單詞讀音，以及設定頁的每日推薦行別，皆新增可複選的濁音「が／ざ／だ／ば」與半濁音「ぱ」。切換片假名時顯示「ガ／ザ／ダ／バ／パ」。
- 手寫、五十音讀音每種字體各有 71 個假名（46 清音、20 濁音、5 半濁音），共 142 個；支援原有重複次數、隨機連續出題、讀音錯題補練、同頁手寫評分及結束總結。
- 濁音、半濁音使用獨立行別。「全部行」現在包含全部 15 行。先前選「全部行」的使用者，更新後的題數會增加；若只想練清音，請改為勾選清音各行。
- 單詞讀音及每日推薦逐字檢查完整讀音。例如「がっこう」需選 が、か、あ 行；「パンダ」需選 パ、ワ、ダ 行。原先清音行隱含的濁音／半濁音，現在必須另行勾選。例句仍採自然日文，不限制整句的行別。
- 手寫筆順含濁點兩筆、半濁點一筆，採 KanjiVG 離線路徑。讀音採 Hepburn；じ／ぢ接受 ji、zi，ぢ另接受 di；づ接受 zu、du。
- 行別選擇與練習歷史沿用既有完整雲端備份；加密設定匯出／還原亦包含新增行別。本機資料格式不變，既有紀錄保留。舊的每日推薦快取重新依新規則判斷，歷史例句不刪除。


## 既有資料與雲端功能

- 登出此裝置只清除本機登入工作階段，不再同時撤銷 Google 授權；另提供「解除 Google 授權」，等待 Google 確認成功才清除登入。開啟 App 直接進入首頁，有效授權沿用；授權到期時操作雲端功能才請求授權。
- 同時需要授權的操作共用一次請求。Google 元件尚未準備好時明確提示稍候重試；驗證必要權限，避免授權不完整仍顯示成功。憑證只保留在 sessionStorage／記憶體。
- Google 錯誤分為授權過期、權限不足、資料夾不存在、配額、頻率限制及服務暫時不可用。僅暫時性讀取錯誤有上限重試；不自動重送可能已成功的上傳。
- 完整備份上傳核對回傳檔案 ID 與 UTF-8 檔案大小才記錄完成；頁面分開顯示完整備份與練習紀錄同步範圍、時間。
- IndexedDB 升級為 schema 3，單字、例句及其他陣列改為逐筆資料與順序索引；更改一筆不重新寫入所有內容。啟動資料分批讀取，避免一次取出整個 records store。舊版資料來源保留於 `migration-v3:*` 供救援。
- 支援 Web Locks 的瀏覽器採單一寫入視窗。第二個視窗顯示說明，須關閉原視窗後重新載入，避免舊快取覆寫資料。
- 手寫、五十音與單詞讀音紀錄清除時保存刪除標記，隨雲端同步及完整備份移轉；舊裝置的同一筆紀錄不會在新版重新出現。練習天數不因清除細項而刪除。
- 各裝置雲端狀態檔只追加自己的新貢獻，不再每次複製所有裝置的完整合併歷史。未完成的同步維持待同步狀態，App 開啟／回到前景且連線授權有效時補同步。
- 背景工作可重用 Worker；不支援 Worker 時限制大型同步 fallback，避免直接卡住主執行緒。
- 已安裝版使用同一 build 的本機程式快取開啟，背景檢查新版；保留啟動自動更新、設定頁目前／最新版本與檢查更新按鈕，練習／傳輸中延後啟用。
- 保存首頁、資料庫、統計及設定頁的捲動位置，調整說明字級、設定寬度及間距；保留貼底導覽、帳戶與雲端置頂、同頁評分及整組完成總結。
- 設定最底部仍是 AES-256-GCM 加密設定匯出／匯入。解密後可選 Google Drive、AI、發音或學習偏好，顯示差異數量；未勾選項目維持現值。API Key 不顯示明文。
- 資料保存區新增「檢查儲存保護」，顯示瀏覽器持久儲存狀態與容量估算，仍應定期備份。

## 更新部署

1. 將 `PWA-Japanese-GD-V1_5_14-FLAT.zip` 解壓縮。將同名資料夾裡的專案檔案放到原 GitHub Pages 位置，使 `index.html` 保持在原網址。
2. 在有現有 Cloudflare 專案權限的環境，於解壓後的資料夾執行以下命令，將提醒 Worker 更新至 V1.4.2。現有 D1 資料表、訂閱與 VAPID 金鑰可繼續使用。

   ```sh
   npm ci
   npm run worker:deploy
   ```

3. Pages 發佈後開啟 App。設定頁的「當前版本」和「最新版本」應顯示 V1.5.14。提醒服務根網址的版本應顯示 V1.4.2。本次發佈沿用 IndexedDB schema 3 及原有 Cloudflare D1 schema。

## 設定檔與資料備份

「加密設定備份」包含 OAuth Client ID、Drive 資料夾、AI Key／模型、學習與發音偏好；不包含 Google access token、通知訂閱或學習資料。匯出的是已儲存值，修改欄位後須先儲存。

使用至少 12 個字元的密碼；PBKDF2-SHA256 600,000 次導出 AES-256-GCM 金鑰，每個檔案使用新 salt／IV。忘記密碼無法解密。學習資料與一般 Google Drive 備份沿用既有格式，本機 IndexedDB 並非全面加密。

## 相容性與界線

- 各裝置建議一起更新，舊版不識別刪除同步標記；手動還原也會遵循新版既有的刪除標記，不復活已刪的練習細項。
- 升級 IndexedDB 後不要直接以舊版程式降版開啟同一資料庫。需要回復時使用備份，不要清除網站資料後再試。
- 持久儲存由瀏覽器核准；手動清除網站資料或解除安裝的保存行為不由 App 保證。
- Google 前端授權憑證會過期，不能保證永久無視窗重新登入。
- 本版仍保留同步資料讀取介面；啟動採分批載入而非所有歷史完全延遲載入。大型備份仍是一次 multipart 上傳，尚非斷點續傳。沒有將整個 App 改寫成新框架。
