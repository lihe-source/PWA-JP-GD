# 日文練習 PWA V1.5.11

本版以 V1.5.10 為基礎，優化 Google 連線、資料保存、同步及操作介面。檔案維持單層；不用新增伺服器、Google API Key 或更改通知設定。

## 更新內容

- 登出此裝置只清除本機登入工作階段，不再同時撤銷 Google 授權；另提供「解除 Google 授權」，等待 Google 確認成功才清除登入。開啟 App 直接進入首頁，有效授權沿用；授權到期時操作雲端功能才請求授權。
- 同時需要授權的操作共用一次請求。Google 元件尚未準備好時明確提示稍候重試；驗證必要權限，避免授權不完整仍顯示成功。憑證只保留在 sessionStorage／記憶體。
- Google 錯誤分為授權過期、權限不足、資料夾不存在、配額、頻率限制及服務暫時不可用。僅暫時性讀取錯誤有上限重試；不自動重送可能已成功的上傳。
- 完整備份上傳核對回傳檔案 ID 與 UTF-8 檔案大小才記錄完成；頁面分開顯示完整備份與練習紀錄同步範圍、時間。
- IndexedDB 升級為 schema 3，單字、例句及其他陣列改為逐筆資料與順序索引；更改一筆不重新寫入所有內容。啟動資料分批讀取，避免一次取出整個 records store。舊版資料來源保留於 `migration-v3:*` 供救援。
- 支援 Web Locks 的瀏覽器採單一寫入視窗。第二個視窗顯示說明，須關閉原視窗後重新載入，避免舊快取覆寫資料。
- 手寫、五十音與單詞讀音紀錄清除時保存刪除標記，隨雲端同步及完整備份移轉；舊裝置的同一筆紀錄不會在新版重新出現。練習天數不因清除細項而刪除。
- 各裝置雲端狀態檔只追加自己的新貢獻，不再每次複製所有裝置的完整合併歷史。未完成的同步維持待同步狀態，App 開啟／回到前景且連線授權有效時補同步。
- 背景工作可重用 Worker；不支援 Worker 時限制大型同步 fallback，避免直接卡住主執行緒。
- 已安裝版使用同一 build 的本機程式快取開啟，背景檢查新版；保留啟動自動更新、設定頁目前／最新版本與檢查更新按鈕，練習／傳輸中延後啟用。
- 保存首頁、資料庫、統計及設定頁的捲動位置，調整說明字級、設定寬度及間距；保留貼底導覽、帳戶與雲端置頂、同頁評分及整組完成總結。
- 設定最底部仍是 AES-256-GCM 加密設定匯出／匯入。解密後可選 Google Drive、AI、發音或學習偏好，顯示差異數量；未勾選項目維持現值。API Key 不顯示明文。
- 資料保存區新增「檢查儲存保護」，顯示瀏覽器持久儲存狀態與容量估算，仍應定期備份。

## 更新部署

1. 先在舊版匯出學習資料備份，並保存加密設定檔及密碼。
2. 解壓縮 `PWA-Japanese-GD-V1_5_11-FLAT.zip`。將同名資料夾**裡面的檔案**覆蓋原 GitHub Pages 位置，讓 `index.html` 保持在原路徑；不要把外層資料夾也當成網站子路徑。
3. 等 GitHub Pages 發佈完成，關閉其他開啟的同一 App 視窗，再開啟 App 或至設定按「檢查更新」。確認目前版本 V1.5.11。
4. 第一次啟動會升級本機資料，完成後檢查單字與歷史紀錄，並做一次完整備份。

本版未變更 Cloudflare 通知 API 或 D1 schema，無須重新執行 db:init 或部署 Worker。此交付不會自動推送 GitHub。

## 設定檔與資料備份

「加密設定備份」包含 OAuth Client ID、Drive 資料夾、AI Key／模型、學習與發音偏好；不包含 Google access token、通知訂閱或學習資料。匯出的是已儲存值，修改欄位後須先儲存。

使用至少 12 個字元的密碼；PBKDF2-SHA256 600,000 次導出 AES-256-GCM 金鑰，每個檔案使用新 salt／IV。忘記密碼無法解密。學習資料與一般 Google Drive 備份沿用既有格式，本機 IndexedDB 並非全面加密。

## 開發檢查

```sh
npm ci
npm run check
npm test
```

語法及 194 項回歸測試通過；另以 IndexedDB 模擬環境驗證 v2 → v3 資料升級、交易中止、重新載入與一萬筆單字編輯／排序後內容一致。此為正確性測試，並非真機效能數字。

本次瀏覽器圖形測試因執行環境限制無法完成，沒有宣稱 iPhone／iPad 真機驗證通過；Google 真實帳戶授權、Drive 上傳與 iOS 音訊仍需在實際部署環境驗收。

## 相容性與界線

- 各裝置建議一起更新，舊版不識別刪除同步標記；手動還原也會遵循新版既有的刪除標記，不復活已刪的練習細項。
- 升級 IndexedDB 後不要直接以舊版程式降版開啟同一資料庫。需要回復時使用備份，不要清除網站資料後再試。
- 持久儲存由瀏覽器核准；手動清除網站資料或解除安裝的保存行為不由 App 保證。
- Google 前端授權憑證會過期，不能保證永久無視窗重新登入。
- 本版仍保留同步資料讀取介面；啟動採分批載入而非所有歷史完全延遲載入。大型備份仍是一次 multipart 上傳，尚非斷點續傳。沒有將整個 App 改寫成新框架。
