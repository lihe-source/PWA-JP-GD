# 日文練習 PWA V1.5.8

以 V1.5.7 為修改基底，不包含已取消的 V1.6 架構。保留七種練習、每日推薦、手寫同頁評分、完成總結及貼底導覽。網站可在 GitHub Pages 的 `/PWA-JP-GD/` 子路徑使用。本 ZIP 只提供完整檔案，沒有自動部署。

## V1.5.8 — 每日推薦分別選擇平假名與片假名（2026-10-19）

- 設定 → 學習設定 → 每日推薦學習設定，分別選擇平假名及片假名的行；兩組都有「全部行／不練習」並支援複選、立即保存。
- 兩組同時啟用時，每次產生隨機選一組，仍推薦一個單字；只啟用片假名時推薦自然以片假名書寫的詞。兩組皆停用時提示至少選一行，不發出生成請求。
- 整段讀音必須符合所屬組別的行，不能借用另一組的行；濁音／半濁音歸原行，拗音須包含相應行，促音及長音符沿用原規則。這是推薦詞的限制，例句本身仍採自然日文。
- 片假名讀音保留片假名；常見半形片假名正規化後再驗證。未取得符合範圍的詞會明確提示，不放寬條件或補造單字。
- 舊版行別遷移至平假名，片假名預設不練習。雲端完整備份與還原包含兩組選行；舊備份仍可使用。設定變動會使不符的今日推薦快取失效，既有例句歷史保留。
- 版本、離線快取、手動及啟動自動更新標記一致；保留 56 個同層檔案。通知後端及資料庫格式不變。

語法檢查及全部 171 項回歸測試通過，其中新增 7 項涵蓋分組過濾、舊設定遷移、快取、模擬 AI 回覆、備份與還原。Chromium 的 430×932、820×1180、1280×800 尺寸檢查亦通過，確認獨立選行、設定保留及無水平溢出。生成流程使用模擬 API；尚未以使用者的真實 Gemini 金鑰及帳務權限驗證，先前模型連線問題仍需原始錯誤碼才能確認。

## V1.5.7 修正（2026-10-15）

- 設定頁需要更新時保留輸入、展開狀態、焦點及可見位置；帳戶與雲端維持第一組，資料保存維持最後。備份傳輸狀態沿用原地更新。
- 作文與 AI 詢問保存本機草稿；切換練習模式、重出題目及離開頁面使用一致的離開確認。草稿只在這台裝置保存，不納入雲端備份。
- 閱讀題、作文批改、文章翻譯及 AI 詢問加入取消與頁面工作識別，離開後的舊回覆不能建立隱藏練習或改寫新畫面；長任務最多 90 秒、共 3 次生成請求。取消不能撤銷供應商已處理的請求。
- 單字、例句及練習集合格式異常時停止覆寫，保留原始內容；救援匯出可保存原始異常資料且排除金鑰與 token。這種標有 recoveryOnly 的救援檔供修復使用，不能當一般備份直接匯入。
- 修正通知訊息計時競爭、單詞羅馬拼音混用別名判定、讀音結果水平溢出及重複底部留白；鍵盤開啟時調整題目區可視範圍，保留同一輸入節點。
- AI 詢問歷史每頁 20 筆；手寫／讀音統計快取會在新增、替換及還原後失效。完整備份分批準備資料、檢查快照一致性，一鍵 ZIP 匯出可取消且在不同資料集間讓出主執行緒。
- 保留手寫同頁分數、整組完成總結、貼底導覽、每日多筆例句及既有通知。完整包為 56 個同層檔案；IndexedDB Schema 2、備份 Schema 3 不變。

驗證包含語法檢查、164 項自動回歸測試，以及 Chromium 手機／平板／桌面尺寸的設定狀態、草稿、切頁與取消操作檢查。真實 iOS 鍵盤、Apple Pencil、音效及 Google Drive／Gemini／推播仍需實機與帳戶驗證；大型單一 CSV 轉換仍可能短暫占用主執行緒，未進行歷史資料索引搬移。

## V1.5.6 修正（2026-10-09）

- 修正備份狀態列的取消按鈕被排入 18px 窄欄，造成文字直排與卡片被撐高。狀態列只有圖示、訊息、操作三欄，按鈕橫排且保留空間。
- 狀態區在操作前即顯示簡短提示；開始、取消、成功、失敗都沿用同一區域，不插入／移除高面板。
- 上傳成功或授權過期不再重建設定頁，原地更新上次同步時間、帳戶狀態與結果；保留捲動位置、展開狀態及未儲存的輸入。上傳期間暫停還原及手動同步按鈕，避免競爭操作。
- 「帳戶與雲端」移到設定首位，新使用者預設展開；既有展開偏好繼續沿用。資料保存仍在設定最下方。
- 底部通知可自動換行、限制寬度，不因取消訊息太長超出手機畫面。底部導覽與手寫練習配置未改動。
- 完整包仍為 54 個同層檔案，語法及 154 項回歸測試通過。UI 行為測試使用模擬 DOM，尚未在 iOS 真機或真實 Google Drive 驗證。

## V1.5.5 優化

- 首頁例句按日期分組，每頁 10 筆；單字庫每頁 40 筆，新增本機搜尋、排序快取及跨頁勾選，不刪減歷史資料。首頁移除與底部導覽重複的三個捷徑。
- 設定分成學習、帳戶與雲端、AI 與通知、進階與資料管理四組，可記住展開狀態；資料保存區仍在最下方。表單採 16px 字體，主要小型控制至少 44px；彈窗支援焦點限制、Escape 與關閉後焦點復原。
- 五十音／單詞讀音送出後立即換題，保留同一輸入節點；上一題訂正留在畫面。進度分開列出原定題數及追加補練，結果列出首輪正確率，補練不混入首輪統計。
- Gemini 實際生成與設定頁共用同一模型目錄，依 API Key 查詢可用文字模型，記憶體快取 6 小時；排除影像／語音端點。金鑰更換後，舊回覆不會保存。模型目錄首次查詢最多 12 秒；短例句／推薦生成本身另有 60 秒和 3 次請求上限。
- 備份的 JSON 解析、checksum、結構驗證及逐筆比較移至模組 Web Worker；雲端傳輸支援取消及完整回應逾時控制，不顯示虛構進度百分比。匯入與匯出統一 25 MiB 上限。
- 修正讀音紀錄 JSON 損壞時可能被寫成空陣列的情形；自動還原會再次核對本機資料，切換帳戶／資料夾後過期的下載與還原不能提交。
- 啟動先呈現載入狀態，逐筆紀錄每 400 筆讓出主執行緒；有效 Google 工作階段直接復用，過期時不在啟動彈出授權，只在使用者主動使用雲端功能時重新授權。
- 統計區分練習天數與場次，將滾動區間正名為「近 30 天」，儲存 Schema 顯示實際值；更新檢查區分舊部署與有新 build 編號的刻意回退。

V1.5.5 發布時共 54 個同層檔案；新增 Gemini、背景工作、資料 Worker、UI 行為四個模組和一個測試檔。該版 150 項自動測試通過。IndexedDB Schema 仍為 2、備份 Schema 仍為 3；舊 Schema 1／2 備份保持相容。`worker.js`、`schema.sql`、`wrangler.toml` 與 V1.5.4 完全一致，無須重新部署通知 Worker、執行 `db:init` 或更換 VAPID 金鑰。

Web Worker 不受支援或無法建立時採相容執行路徑，該情況無法保證大型備份不占用主執行緒。這次沒有將所有 KV 歷史搬移至新索引，也沒有宣稱已消除真機手寫延遲。

- 雲端備份按紀錄身分比較，分岔資料不因筆數較多就自動覆蓋；同日多次練習及多筆例句保留。

- PWA 更新會等待儲存與使用中頁面安全，再切換新版；保留上一版快取作離線回退。

完整技術變更見 `CHANGELOG.md`。手寫卡頓診斷可在設定頁開啟；桌面回歸測試無法證明 iPhone、iPad 及 Apple Pencil 的真機延遲已消失。

交接文件中的長期結構項目仍需後續分版處理：將所有例句搬成逐筆索引、5 萬筆資料效能基準、Worker 端限流與跨表原子修復，以及裝置上的音訊／推播／手寫實測。本版沒有執行這些高風險資料搬移或雲端部署。

## 使用完整 ZIP

解壓後，ZIP 內只有一層同名資料夾。需要自行發布時，將該資料夾**內**的檔案放在 Repository 根目錄，使 `index.html` 位於根目錄。不要上傳外層資料夾、`node_modules` 或先刪除網站資料。這次沒有替使用者寫入 GitHub 或 Cloudflare。

更新前先在設定頁匯出救援備份。更新後檢查首頁及設定頁版本都是 V1.5.8，並實測上傳成功、取消傳輸、設定順序與一輪練習。現有 IndexedDB、Google OAuth 設定、D1 綁定及 VAPID Key 不因本版改變。

本次只需更新前端檔案。不要因前端版本更新重新建立 D1 或重新產生 VAPID 金鑰；通知後端未改動。

## 本機檢查

Node.js 20 以上：

```bash
npm ci
npm run check
npm test
```

前端是靜態檔案，不需要 npm build。Worker 設定見 `wrangler.toml`；已建立 D1 的使用者不要為前端更新重新建立資料庫或更換 VAPID 金鑰。

真實 Gemini Key、Google 帳號、Drive 寫入、Cloudflare 推播及 iOS 真機鍵盤／手寫／通知，需在使用者環境另外驗證。金鑰、access token、VAPID 私鑰不包含在 ZIP 或備份中。Google 工作階段失效時可能需要再次授權。

第三方素材與套件授權見隨附 LICENSE／NOTICE；架構說明見 `ARCHITECTURE.md`。
